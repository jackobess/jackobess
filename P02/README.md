# 🎓 P2 – Analyse exploratoire : données éducatives mondiales

Projet du parcours *Data Scientist Machine Learning* (OpenClassrooms).

Analyse exploratoire des données EdStats de la Banque mondiale pour aider une EdTech à choisir les pays où s'implanter : nettoyage et sélection des indicateurs pertinents, puis scoring pondéré des pays selon leur potentiel.

**Stack :** Python · pandas · NumPy · matplotlib · seaborn · Jupyter
