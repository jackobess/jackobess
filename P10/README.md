# 🏀 P10 – Évaluer les performances d'un LLM : assistant NBA

Projet du parcours *Data Scientist Machine Learning* (OpenClassrooms).

Audit et amélioration d'un assistant RAG sur la NBA : extraction des sources (OCR), structuration des données avec Pydantic AI, ajout d'un outil NL→SQL pour les questions statistiques, puis évaluation avant / après avec Ragas et suivi des appels avec Logfire.

**Stack :** Python · RapidOCR · Pydantic AI · Mistral AI · SQL · Ragas · Logfire
