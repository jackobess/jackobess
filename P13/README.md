# 🤖 P13 – AskJack : mon parcours et mes projets IA

Projet technique personnel de fin de parcours *Data Scientist Machine Learning* (OpenClassrooms).

AskJack est un assistant RAG qui répond aux questions des recruteurs sur mon parcours, mes compétences et mes 13 projets de formation. Il s'appuie sur mon CV, mes fiches projets, mes présentations de soutenance et les README de mes dépôts.

**Stack :** Python · FAISS · Mistral (embeddings + LLM) · Streamlit · Streamlit Community Cloud · GitHub

**Statut :** v1 en ligne, évolutions prévues après la formation.
