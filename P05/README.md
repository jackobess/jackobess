# ⚙️ P5 – Déployer un modèle de Machine Learning

Projet du parcours *Data Scientist Machine Learning* (OpenClassrooms).

Mise en production du modèle du P4 (attrition RH) : API FastAPI connectée à une base PostgreSQL pour journaliser les prédictions, 33 tests Pytest, pipeline CI/CD GitHub Actions et déploiement automatique sur Hugging Face Spaces.

**Stack :** Python · FastAPI · Pydantic · PostgreSQL (Neon) · Pytest · GitHub Actions · Hugging Face Spaces

### Notes de l'évaluateur

- **Configurer l'environnement de travail** : Environnement correctement configuré, requirements.txt complet et pertinent, configuration documentée et testée, installation automatisée et fonctionnelle.
- **Définir et formaliser les processus de traitement et de stockage des données** : Processus de stockage et de gestion des données clairement décrits dans le README, besoins analytiques précisés, processus conforme, structuré et compréhensible.
- **Établir et exécuter un processus de test du SGBD** : Méthodologie de tests complète, intégrité des données garantie, requêtes fonctionnelles et tests Pytest couvrant les cas critiques, rapport de couverture démontrant la robustesse du code.
- **Installer et paramétrer un SGBD et un outil d'extraction** : Base initialisée par script, SGBD et outil d'extraction paramétrés de manière pertinente, tables et relations créées, extraction fonctionnelle.
- **Mettre en place un système d'authentification afin de garantir la sécurité des données** : Méthodes d'authentification et de gestion des accès documentées, bonnes pratiques de sécurité appliquées (gestion des secrets, hachage des mots de passe), système conforme et opérationnel.
- **Modéliser une infrastructure compatible avec le SI** : Pipeline CI/CD fonctionnel et API déployée.
- **Structurer l'architecture des données et concevoir des BDD** : Schéma de base clair et complet, base créée par script, dataset et exemples insérés, relations, contraintes et structure correctement définies pour le volume de données.
